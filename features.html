Features

Everything in Orbi 2.0

Workspaces, dock, tabs, sessions, and focus — designed as one local-first system for Chrome.

Spaces

Create Work, Personal, Research, or your own spaces. Switching restores context; save and restore window tabs per space.

Smart dock

Edge dock with configurable pin limit, folders, drag reorder, favicons, and frequency-based suggestions — always a peek away on any page.

Tab command center

Search across windows, pin, mute, close, or duplicate. Group by domain and hibernate idle tabs with tabs.discard.

Sessions

Named save and restore, automatic snapshots via alarms, and a light session diff so you can see what changed.

Focus mode

Hide dock and peek, apply allowlist or blocklist rules, run a timer. Toggle with Ctrl/Cmd+Shift+F.

Clock & New Tab

Customizable clock and date on New Tab, live wallpapers, and a calm dashboard that feels like yours.

Shortcuts

Add from the popup or dock, pin the ones that matter, organize into folders, and open from New Tab or any site.

Command palette

Ctrl/Cmd+K on New Tab for quick actions. Options page covers export/import and keyboard docs.

Productivity extras

Space-scoped notes, read-later inbox, daily todos, and local usage insights — still offline-first.
