Support

Install tips, common questions, and how to reach us.

Load unpacked (dev)

  1. Open chrome://extensions
  2. Enable Developer mode
  3. Load unpacked → select the extension folder in this repo
  4. Open a new tab to see Orbi

Full notes live in extension/README.md.

Common questions

  • Where is my data? On your device in Chrome extension storage. See Privacy.
  • Can I back up? Yes — export JSON from Options (full or per-space).
  • Focus shortcut? Ctrl/Cmd+Shift+F. Palette on New Tab: Ctrl/Cmd+K.
  • Why host permission? Dock on pages, favicons, and tab preview capture — not for selling data.
